### 🚀 Featured Project

**CloudStore** — a Dropbox-style distributed file storage system
- Built with **FastAPI, PostgreSQL, gRPC, Redis, Docker Compose**
- Phase 1: JWT auth & file management
- Phase 2: Chunked replication across storage nodes
- Phase 3: Heartbeat monitoring with auto-re-replication
- Design informed by a deep study of the **Google File System (GFS)** paper — chunk sizing, metadata design, and re-replication priority
